How the Video is Created — Full Pipeline
Overview
MAL API → Trending Manga → MangaDex API → Chapter Pages
→ Download Images → AI Selects Best Panels
→ FFmpeg Renders Video → DB stores it → TikTok Upload
Step 1 — Find Trending Manga (every 4 hours)
n8n Workflow 01 + scripts/fetch_trending_manga.py

The system calls MyAnimeList API to get the top 20 trending manga ranked by a score formula:

score = rating (60%) + rank (25%) + popularity (15%)
Results are saved into the manga table in Supabase with their trending_score.

Step 2 — Fetch Chapter from MangaDex
scripts/fetch_chapter_images.py

For each active manga, it calls the free MangaDex API:

Gets the latest English chapter using /manga/{id}/feed
Skips licensed chapters (Viz/Shonen Jump) that MangaDex doesn't host
Gets the full-resolution page image URLs from /at-home/server/{chapter_id} — this is MangaDex's CDN system
Saves the chapter + all page URLs to manga_chapters table
Example URL format stored:

https://uploads.mangadex.org/data/{hash}/page-001.jpg
Step 3 — Download Panel Images
scripts/download_panels.py

Downloads the actual image files from MangaDex CDN to local disk:

Saves to data/panels/{manga_title}/ch_{chapter}/panel_001.jpg
Retries 3 times on failure with exponential backoff
Skips already-downloaded panels
Updates manga_chapters.local_paths in DB with the file paths
Step 4 — AI Selects the Best Panels
mastra-agents → agents/panelSelector

This is where Claude AI gets involved. It analyzes all downloaded panels and picks the 3–5 most engaging ones for social media based on:

Emotion — epic, shocking, funny, sad, romantic
Visual impact — action shots, expressive faces
Story hook — panels that make viewers curious
The selected panels (with scores and reasoning) are saved to the selected_panels table as JSON.

Step 5 — Generate the Video
scripts/generate_video.py → scripts-bash/generate_manga_video.sh

This is where FFmpeg does the heavy lifting. The Python script reads the selected panel paths from the DB and calls the bash script. The bash script runs 4 sub-steps:

Sub-step A — Ken Burns Effect on each panel
Each panel image gets a cinematic motion effect using FFmpeg's zoompan filter:

Even panels → zoom in from center (scale 1.0 → 1.5x)
Odd panels → pan left to right
# Zoom in example
zoom='min(zoom+0.0015,1.5)':d=120:x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)'
Each panel runs for 4 seconds at 30fps = 120 frames, rendered at 1080×1920 (9:16 vertical for TikTok).

Sub-step B — Crossfade transitions between panels
FFmpeg's xfade=transition=fadeblack filter blends each panel into the next with a 0.5 second fade-to-black transition.

Sub-step C — Title card overlay
The manga title and chapter number are burned into the first 3 seconds of the video using drawtext filter with white text + black shadow:

"One Piece — Chapter 1100" (top of screen, first 3 seconds)
Sub-step D — Background music (optional)
If a music file exists at data/music/, it's mixed in at 40% volume with a 2-second fade-out at the end.

Final output: an .mp4 file at data/videos/{title}_ch{num}_{timestamp}.mp4

Step 6 — AI Generates Caption + Hashtags
mastra-agents → agents/captionGenerator

Claude reads the video metadata and manga info and generates:

A TikTok-optimized caption (hook + emotion)
Relevant hashtags (#manga, #anime, #[title], etc.)
These are saved back to the videos table.

Step 7 — Upload to TikTok
scripts/upload_tiktok.py → TiktokAutoUploader

Picks the next available active account from tiktok_accounts (respects daily upload limit of 3)
Loads saved session cookies from TiktokAutoUploader/CookiesDir/tiktok_session-{name}.cookie
Uses HTTP requests (no browser) to upload the video to TikTok's internal API
Records the result in upload_results and published_videos tables
Updates tiktok_accounts.last_post_at
Final Numbers for a 5-panel video
Duration	~18s (5 panels × 4s − 4 transitions × 0.5s)
Resolution	1080 × 1920 (9:16)
FPS	30
Codec	H.264, CRF 22
Typical size	8–15 MB
